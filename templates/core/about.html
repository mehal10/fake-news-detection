Project Overview

Fake News Detection and News Sentiment Analysis System is a research-oriented web application that applies natural language processing (NLP) and classical machine learning to news text. It estimates whether an article resembles patterns associated with real or fake news in its training data, and classifies the linguistic polarity of the text as positive, negative, or neutral.

Problem Statement

Online news spreads quickly, and readers often lack time or tools to assess both the stylistic credibility signals of an article and its emotional tone. Manual review does not scale. Automated assistance can flag patterns learned from labelled corpora, while remaining transparent that such outputs are statistical estimates—not verified facts.

Motivation

The project demonstrates an end-to-end applied NLP pipeline: dataset management, preprocessing, feature extraction, model training, evaluation, interactive prediction, history tracking, and analytics—using open-source libraries without paid APIs or proprietary cloud ML services.

Objectives

  • Build a working fake-news classifier (Real / Fake) using TF-IDF and optional Word2Vec features.
  • Build a three-class sentiment classifier (Positive / Negative / Neutral).
  • Support combined analysis of the same article through both pipelines.
  • Persist analyses, expose history search/filters, and report usage and evaluation metrics.
  • Provide educational documentation of NLP and ML concepts used in the system.

Scope

  • In scope: English news-style text, CSV dataset upload, scikit-learn / Gensim models, SQLite history, Chart.js analytics, admin dataset and model management.
  • Out of scope: Live web scraping of news sites, source verification, deep learning transformers, user accounts/authentication, multilingual models.

Applications

  • Academic demonstration of text classification pipelines.
  • Classroom labs on preprocessing, TF-IDF, and evaluation metrics.
  • Internal research prototypes for comparing classical ML algorithms on labelled news corpora.

  1. User enters a headline and/or article body (or uploads a .txt file).

  3. Preprocessing lowercases text, removes URLs and HTML, normalizes whitespace, tokenizes, optionally removes stopwords, and applies stemming or lemmatization.
  4. Feature extraction maps cleaned text to TF-IDF vectors (unigrams/bigrams) or averaged Word2Vec embeddings, using extractors fitted only on training data.
  5. Classification runs the selected trained model (Naïve Bayes or Logistic Regression for TF-IDF; Logistic Regression for Word2Vec document vectors).
  6. Output shows the predicted label, class probabilities, model name, and processing time, with an explicit disclaimer.
  7. Persistence stores successful analyses in SQLite for history, dashboard statistics, and reports.

NLP Concepts

Natural Language Processing (NLP) is the field of methods that enable computers to work with human language. This project focuses on classical, interpretable techniques suitable for classroom and research prototypes.

Text Preprocessing

Standardizes raw text before modelling: casing, noise removal, and normalization so similar words map more consistently.

"The COVID-19 update — see https://ex.com" → "covid update"

Tokenization

Splits text into units (usually words) that models can count or embed.

"not good news" → ["not", "good", "news"]

Stopword Removal

Drops very common words (e.g. “the”, “is”) that often add little class signal. Sentiment mode keeps negation cues such as “not” and “never”.

Stemming

Heuristic shortening of words to a root form (Porter stemmer). Fast but can be crude.

studies, studying → studi

Lemmatization

Maps words to dictionary lemmas using linguistic knowledge (WordNet). More accurate than stemming, slightly heavier.

studies → study · better → good

TF-IDF

Term Frequency–Inverse Document Frequency weights words that are frequent in a document but rare across the corpus. Supports unigrams and bigrams.

Word2Vec

Learns dense vector representations of words from context. Document vectors are formed by averaging available word vectors; unknown words are skipped safely.

Feature Extraction

Conversion of cleaned text into numerical inputs for classifiers. Vectorizers are fitted on training data only to avoid leakage.

Text Classification

Assigning discrete labels to documents. Here: Real/Fake for credibility-style patterns, and Positive/Negative/Neutral for sentiment.

Sentiment Analysis

Estimates linguistic polarity of text. It does not measure factual truth or source reliability.

Machine Learning Algorithms

Multinomial Naïve Bayes

Introduction. A probabilistic classifier based on Bayes’ theorem with a strong independence assumption between features. Multinomial NB is well suited to discrete counts such as TF-IDF or raw term frequencies.

How it works. It estimates the probability of each class given the feature vector by combining per-feature likelihoods with the class prior, then selecting the maximum a posteriori class.

Role in this project. Used for fake-news detection and optional sentiment classification on TF-IDF features. Not used with Word2Vec vectors because embeddings can contain negative values incompatible with Multinomial NB.

Advantages. Fast training and prediction; strong baseline on sparse text; few hyperparameters (e.g. smoothing α).

Limitations. Independence assumption is unrealistic; can underperform when features are highly correlated; limited capacity versus denser models on complex semantics.

Logistic Regression

Introduction. A linear classifier that models the log-odds of class membership as a weighted sum of features, mapped through a logistic (or softmax for multiclass) function.

How it works. Coefficients are learned by maximizing likelihood with regularization (L2 by default in this project). Softmax extends the same idea to three sentiment classes.

Role in this project. Primary classifier for TF-IDF fake-news and three-class sentiment models; also used on averaged Word2Vec document vectors.

Advantages. Interpretable weights; reliable probabilities when calibrated; handles many sparse features with regularization; works with dense embeddings.

Limitations. Decision boundary is linear in feature space; performance depends heavily on feature quality; may need careful regularization on small datasets.

Word2Vec-based Document Classification

Introduction. Combines unsupervised word embeddings with a supervised classifier. Each document is represented as the mean of its word vectors.

How it works. Word2Vec (Gensim) is trained on the training corpus. At inference, tokens present in the vocabulary are averaged; empty or all-OOV documents become zero vectors. Logistic Regression then classifies the dense vector.

Role in this project. Alternative fake-news pathway to compare against TF-IDF + NB/LR under the same train/test split when a Word2Vec model has been trained and registered.

Advantages. Captures distributional similarity; fixed-size vectors independent of vocabulary size; can generalize to related wording.

Limitations. Mean pooling loses word order; rare words and domain shift hurt quality; requires enough text to train meaningful embeddings; not paired with Multinomial NB here.

Limitations and Disclaimer

  • Predictions depend on the quality, size, balance, and domain of the training data.
  • Machine learning models can and do make incorrect predictions on unseen text.
  • Sentiment scores reflect linguistic polarity patterns—not whether a claim is true.
  • Fake/Real labels reflect similarity to training examples—not independent fact verification.
  • The system does not check sources, authors, timestamps, or external knowledge bases.
  • Outputs must not replace manual fact-checking or professional journalistic review.
  • Small sample datasets yield unstable metrics; treat demo accuracies as illustrative only.

By using this application you acknowledge that all model outputs are statistical estimates derived from historical labelled text and are provided for research and educational purposes.
